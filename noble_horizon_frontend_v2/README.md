```text
noble_horizon_frontend_v2/
│
```

## Theme

The new theme is based on the Noble Horizon logo:

- Deep navy
- Rich gold
- Warm white / cream
- Premium serif headings
- Clean modern body typography

## Run locally

Open this folder in VS Code.

Then open:

`index.html`

Right-click and select:

`Open with Live Server`

## Important

Do not copy the old CSS into this project.

This stylesheet was written from scratch to match this HTML.
